# Nifty Intraday Options Trading Bot (Breeze API)

## Module 1-10: Core Engine, Database & Alerts
- **Market Data:** WebSocket ticks to 1m, 3m, 5m candles.
- **Strategies:** Momentum, ORB, Trend Continuation with AI filtering.
- **Risk & Execution:** Capital protection, auto-sizing, multi-target exits.
- **Database:** SQLite persistence for trades, signals, and metrics.
- **Telegram:** Real-time notifications for all trading events.

## Module 11: Live Dashboard

### Architecture Explanation
The Dashboard provides a real-time web interface to monitor the bot's performance, open positions, and signal quality.

- **Data Provider (`dashboard/data_provider.py`):** Bridges the SQLite database and the UI, calculating real-time metrics like Win Rate and Equity curves.
- **Web App (`dashboard/app.py`):** Built with **Plotly Dash**, featuring:
  - **Equity Curve:** Visualizes cumulative PnL over time.
  - **Signal Distribution:** Shows the quality of signals generated by the AI filter.
  - **Live Trades Table:** Displays details of all current and historical trades.
  - **Performance Cards:** Win Rate, Total PnL, and Total Trade count.

### Running the Dashboard
The dashboard starts automatically when you run `main.py`. You can access it at:
`http://127.0.0.1:8050`

To start the bot **without** the dashboard:
```bash
python3 main.py --no-dashboard
```
